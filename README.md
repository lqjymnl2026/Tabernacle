# 云会幕 · Tabernacle

全球线上教会 × 全圣经互动 × AI 多语言 × 线上神学院 × 小组社区

> 「云会幕」不是把教会搬到网上，而是重新设计一个属于数字时代的教会。
> 圣经是内容核心 · 教会是关系核心 · AI 是工具 · 多语言是连接世界的桥梁。
