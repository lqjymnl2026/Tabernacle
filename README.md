# 云会幕 · 教会影院 + 线上神学院

看道 · 学道 · 行道 —— 教会影院 × 线上神学院

## 页面一览

| 入口 | 文件 | 说明 |
|------|------|------|
| 🏠 首页 | `index.html` | 影院 + 神学院入口、精选影片、正在直播 |
| 🎬 影院 | `cinema.html` | 影片库：分类筛选 + 搜索 |
| ▶️ 播放页 | `watch.html` | 点播播放器 + 关联经文 + 笔记 |
| 🔴 直播间 | `live.html` | 直播聚会：AI 多语言字幕 + 聊天 + 投票 + 代祷 |
| 🎛️ 直播后台 | `live-admin.html` | 直播场次 / 弹幕审核 / AI 字幕翻译 / 设置 |
| 🎓 神学院 | `seminary.html` | 4 级课程体系 + 课程列表 + 互动课堂 |
| 📚 课程详情 | `course.html` | 课时列表 + 讲师 + 证书要求 |
| ▶️ 视频课 | `lesson.html` | 课程播放 + 随堂测验 + 笔记 + 讨论 |
| ⚙️ 管理后台 | `admin.html` | 数据看板 / 影片 / 课程 / 评论审核 / 用户 |

## 技术

- 纯静态 HTML + CSS + JS（原型阶段）
- 共享设计系统：`assets.css` / `assets.js`
- 可部署到 GitHub Pages / Netlify / Vercel / Cloudflare Pages

## 创意路线（特色功能规划）

1. **AI 实时多语言字幕**：一场直播，12 种语言同时参与
2. **自动识别经文**：视频里提到经文 → 一键打开
3. **看道 → 学道闭环**：影片看完一键进入对应神学课程
4. **随堂测验 + 结业证书**：看完即测，完成课程得证书
5. **教会影院 × 神学院双引擎**：内容（影片）与装备（课程）互相导流

## 路线图

1. MVP：影片库 + 播放 + 神学院课程
2. 直播：直播间 + 直播后台 + AI 字幕
3. AI：翻译 / 经文识别 / 笔记 / 测验
4. 社区：讨论 / 见证 / 代祷 / 证书体系
